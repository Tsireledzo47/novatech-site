Support Escalation Procedure

At NovaTech Solutions, all IT incidents follow a structured escalation model designed to ensure timely resolution, accountability and continuous communication. Tickets that exceed SLA thresholds or require specialized expertise are automatically escalated from Service Desk to Specialist, to Team Lead, and to Management.

1. Log
Ticket created with unique ID and SLA timer
2. Triage
Reviewed within 15 minutes, priority validated
3. Assign
Routed to qualified specialist by category
4. Resolve
Active investigation with progress updates
5. Escalate
Escalated to Lead / Management if SLA at risk
6. Closure
Fix verified, documented and formally closed

Knowledge Base

Self-help library — resolve common issues without waiting for support.

💻 Software — Application Crashing

Record error message, restart application and computer, install approved updates via Help > Check for Updates. Avoid unauthorised software installations which cause 40% of crashes.

📶 Network & WiFi — No Internet

Check if issue affects multiple users, toggle WiFi OFF/ON, reconnect to NovaTech-Staff, restart device, test with LAN cable.

📧 Email — Outlook Not Sending

Verify internet, Send/Receive > Update Folder, remove attachments over 25MB and share via OneDrive link, close and reopen Outlook.

🔒 Access — Shared Folder Denied

Ensure VPN or corporate WiFi connection, sign out/in to refresh permissions, confirm role-based access, log ticket with exact folder path.
