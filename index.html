Knowledge Base — Self-Service Solutions
The Knowledge Base is a centralized self-service library designed to empower users to resolve common IT issues independently without logging a support ticket. Each article explains cause, symptoms and step-by-step resolution.

💻 SOFTWARE — Application Crashes & Errors

Software includes programs like Microsoft Office, Outlook, Teams. A crash occurs when program closes unexpectedly. Record exact error message, restart application, check for updates, restart computer. If still failing, log ticket with screenshot.

🌐 NETWORK — Wi-Fi, Internet & Connectivity

Network issues relate to connection to internet or company Wi-Fi. Symptoms include "No Internet". Check Wi-Fi icon, turn Wi-Fi off and on, select correct network NovaTech-5G, enter password, restart router: unplug 30 seconds, plug back, wait 2 minutes.

🔐 ACCESS — Shared Folders & Permissions

Access issues occur when you try to open shared drive and get "Access Denied". Ensure you are on company network or VPN. Verify path e.g., \\fileserver\finance. Confirm with HR. Submit Access Request ticket with system name and manager approval.

🖨️ HARDWARE — Printer & Peripherals

Hardware covers printers, scanners, monitors. Printer not printing or offline is common. Check power and network cable. Go to Settings > Devices > Printers > Add Printer > Select printer. Install driver. Print test page.

📧 EMAIL — Outlook Not Working

Email problems include Outlook not sending/receiving, stuck offline. Check internet, check bottom bar: if Offline, click Work Offline to disable. Check password expired, restart Outlook, try webmail at outlook.office.com.

🔑 PASSWORD — Account Locked or Forgotten

Password issues include forgotten password, account locked after 3 wrong attempts, or expired after 90 days. On login click Forgot Password > Enter work email > Check inbox for reset link > Create new strong password.

Our Departments
This section explains core departments that work together to deliver efficient IT services.

🏢 IT Department

Technical operations and helpdesk support — the backbone of NovaTech Solutions.

The IT Department is responsible for overall infrastructure management including servers, networks, firewalls, switches and wireless access points. It manages system integration, ensures cybersecurity, provides helpdesk support via ticket system, monitors performance through dashboards, and maintains asset register to track equipment lifecycle.

👥 HR Department

People and access management — focusing on human capital and employee experience.

The HR Department focuses on talent acquisition, recruitment and onboarding. It manages employee access requests for shared folders, emails and systems, oversees training and development, handles leave and performance management, ensures compliance with labour laws, and coordinates with IT for account creation and access revocation.

💰 Finance Department

Asset and budget control — ensuring financial health and cost-effective IT operations.

The Finance Department oversees budgeting, procurement and asset valuation for all IT equipment and software licenses. It tracks total asset balance, calculates depreciation and total cost of ownership, approves purchases, manages vendor payments, controls IT expenditure, and works with IT to prioritize asset replacement based on age and warranty expiry.
